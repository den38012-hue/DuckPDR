DuckPDR — версия для GitHub Pages

ВАЖНО: загружайте ВСЕ содержимое этой папки в корень репозитория:
index.html
app.js
data.js
style.css
images/

Не создавайте дополнительную папку pdr_final внутри репозитория.

После загрузки:
1. GitHub → Settings → Pages
2. Source: Deploy from a branch
3. Branch: main
4. Folder: / (root)
5. Save

Если сайт открывается, но тестов нет, проверьте, что data.js находится рядом с index.html.
